# Travel_demand_prediction_using_gravity_model
this repository employs gravity model using python to predict the number of cars traveling between two cities uisng the gravity model formula
〖flow〗_ij=  (P_i^α* P_j^β)/(D_ij^γ ),
Where 〖flow〗_ij represents the predicted number of cars from city (i) to city (j), P_i and P_j represent the population size of city (i) and city (j) respectively, D_ij represents the distance between city (i) and city (j) with estimated parameters α, β and γ.
